# 🌐 Sistema de Internacionalização (i18n) - llmCli

O **llmCli** possui suporte nativo e de primeira classe a múltiplos idiomas, permitindo que a interface do terminal, mensagens de status, prompts do sistema e as instruções enviadas para a IA se adaptem automaticamente ao idioma preferido do desenvolvedor.

---

## 🎮 2. Como Usar e Alternar Idiomas

### No Terminal Interativo (REPL):

1. **Exibir o idioma ativo e catálogo:**
   ```bash
   /lang
   ```
2. **Alterar o idioma instantaneamente:**
   ```bash
   /lang en        # Altera para Inglês
   /lang es        # Altera para Espanhol
   /lang pt        # Altera para Português
   /lang de        # Altera para Alemão
   /lang fr        # Altera para Francês
   /lang zh        # Altera para Chinês
   /lang ru        # Altera para Russo
   /lang hi        # Altera para Hindi
   /lang auto      # Detecta automaticamente pelo locale do sistema operacional
   ```

### Na Inicialização via Variável de Ambiente:
Defina no arquivo `.env` ou no ambiente do shell:
```env
LLMCLI_LANG=en-US
```

### No Arquivo de Configuração (`config.yaml`):
```yaml
language: "en-US"
```

---

## 💾 3. Persistência Automática

Quando você altera o idioma via `/lang`, a preferência é salva automaticamente em `~/.llmcli_preferences.json` sob a chave global `"language"`. Nas próximas execuções do `llmCli`, seu idioma preferido será carregado automaticamente.

Para restaurar as configurações padrão:
```bash
/reset prefs
```

---

## 🤖 4. Impacto no Comportamento da IA

Ao alterar o idioma, o `llmCli` realiza duas ações simultâneas:
1. **Interface do Usuário (UI):** Traduz mensagens de status, confirmações, banners, alertas e notificações da CLI.
2. **Instruções de Sistema (System Prompt):** Injeta uma diretriz explícita no System Prompt (`prompt_ai_instruction`) instruindo o modelo a responder e documentar o código no idioma selecionado.

---

## 🛠️ 5. Como Adicionar Novos Idiomas ou Traduções

Todas as mensagens estão centralizadas no módulo [`src/i18n.py`](file:///storage/www/projetos/utils/llmCli/src/i18n.py):

1. Adicione a definição do idioma no dicionário `SUPPORTED_LANGUAGES`.
2. Inclua aliases no dicionário `LANGUAGE_ALIASES`.
3. Adicione o catálogo de chaves traduzidas em `TRANSLATIONS`.
4. Execute os testes com `./scripts/run_tests.sh` para garantir que todas as chaves estão completas e validadas.

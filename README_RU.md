# 🤖 llmCli

> **Language / Язык:** 🇧🇷 [Português](README.md) | 🇺🇸 [English](README_EN.md) | 🇪🇸 [Español](README_ES.md) | 🇩🇪 [Deutsch](README_DE.md) | 🇫🇷 [Français](README_FR.md) | 🇨🇳 [中文](README_ZH.md) | 🇷🇺 [Русский](README_RU.md) | 🇮🇳 [हिन्दी](README_HI.md)

**llmCli** — это современный интерактивный ИИ-ассистент разработчика для терминала (созданный по мотивам OpenAI Codex, Aider и Claude Code), оптимизированный для бесшовной работы как с **локальными LLM** (llama.cpp, Ollama, LM Studio, vLLM), так и с **облачными LLM** (Google Gemini, OpenAI GPT-4o / o-series, Anthropic Claude 3.7 / 3.5, DeepSeek V3 / R1, Groq, OpenRouter).

---

## 🌟 Основные Возможности

- 🔄 **Полная Гибридная Поддержка:**
  - **Локально:** **llama.cpp** (`http://localhost:8080`), **Ollama** (`http://localhost:11434`), **LM Studio** (`http://localhost:1234/v1`), **vLLM** (`http://localhost:8000/v1`).
  - **Облако:** **Google Gemini** (2.5 Flash / Pro), **OpenAI** (GPT-4o / o3-mini), **Anthropic Claude** (3.7 Sonnet / 3.5 Haiku), **DeepSeek** (V3 / R1), **Groq** и **OpenRouter**.
- 🏛️ **Режим Архитектора (`/architect` / `/arch`):**
  - Двухэтапный интеллектуальный процесс: сильная модель (Архитектор) формирует план изменений, а быстрая модель (Редактор) применяет патчи и выполняет инструменты.
- 🌐 **Мультиязычность и Локализация (`/lang`):**
  - Встроенная поддержка 8 языков (**Русский**, **Английский**, **Португальский**, **Испанский**, **Немецкий**, **Французский**, **Китайский**, **Хинди**) с автоопределением по локали ОС (`/lang auto`).
- ⚡ **Режим YOLO (`/yolo`):**
  - Полностью автономная работа без необходимости подтверждать каждое действие вручную.
- 🧠 **Офлайн Семантический Поиск и Локальный RAG (`/index` / `/search`):**
  - AST-индексация функций и классов с алгоритмами BM25 и TF-IDF, 100% локально.
- 🔌 **Поддержка Model Context Protocol (MCP) (`/mcp`):**
  - Динамическое подключение инструментов и серверов MCP.
- 🌐 **Веб-поиск и Чтение URL (`/web` / `read_url`):**
  - Поиск актуальной документации и решений через DuckDuckGo или Tavily API.
- 📋 **Планировщик и Чек-лист Задач (`/plan` / `/todo`):**
  - Автоматическая декомпозиция целей в интерактивный список задач.
- 🧪 **Генерация Тестов и Автоисправление Ошибок (`/gentest` / `/test`):**
  - Создание тестов `pytest` и автоматическое исправление упавших тестов с помощью ИИ.
- 💾 **Сохранение Пользовательских Настроек:**
  - Сохранение модели, режима YOLO, языка и температуры в `~/.llmcli_preferences.json`.
- 📄 **Экспорт Сессий (`/export`):**
  - Экспорт в форматы **Markdown** (`.md`) и интерактивный **HTML** (`.html`).
- 🛡️ **Безопасность и Git Чекпоинты:**
  - Ограничение рамками рабочей папки ([AGENTS.md](file:///storage/www/projetos/utils/llmCli/AGENTS.md)).
  - Автоматические Git-снимки перед каждым изменением и мгновенный откат с помощью `/undo`.

## 🚀 Быстрый Старт

```bash
# 1. Создать и активировать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить переменные окружения
cp .env.example .env

# 4. Запустить интерактивную сессию
./bin/llm-cli
```
